# Logo design

Original device-themed logo generated with the built-in imagegen tool.
PNG preserves generated transparency; ICO only converts the same design to Windows icon sizes.
No logo or security badge from another vendor is used.

## Final prompt

Create a unique app icon for GETEdit, a free PDF page organizer. Device theme: a compact blue desktop document scanner with three visible paper cards emerging in a fanned stack, the front card has two simple blue bars and a small folded corner. Distinctive palette: cobalt blue, icy white and a small coral paper-tab accent. Refined simple geometric product logo, clean flat shapes with restrained soft depth, strong recognizable silhouette at 32px, balanced square composition with generous safe margins. No text, no letters, no PDF lettering, no badges, no shields, no lock, no watermark, no operating-system brand marks. Actual transparent background around the centered icon. Original professional desktop application icon, not a mockup or icon sheet.
